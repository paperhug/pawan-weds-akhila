# Wedding invitation website

This folder is self-contained for the site's local assets. Open `index.html` to preview it, or publish the folder contents to GitHub Pages. Keep the HTML, CSS, JavaScript, font, and image files together in the same folder.

## Replaceable files

- Add the music file beside `index.html` and name it `music.mp3`. The site keeps this filename as a placeholder until you add the audio.
- Replace `event-1.png`, `event-2.png`, and `event-3.png` to update the event cards. The filenames are referenced directly by `index.html`.
- Replace any other image or `amoresa-regular.woff2` with a file of the same name to update that resource.
- Replace each `href="#"` in `index.html` with the relevant Google Maps location link.
- All welcome and invitation wording is editable in `index.html`.

Google Fonts are loaded from Google Fonts when the site is online; the included Amoresa font is local.
